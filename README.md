# SCM Integrated Platform

Global Supply Chain Management Integrated Platform for Manufacturing.

## Overview
This platform is designed to provide comprehensive supply chain management capabilities, including demand forecasting, inventory optimization, procurement optimization, logistics management, and risk management.

## Key Features
- **Demand Forecasting**: Machine learning-based forecasting using Prophet and LSTM.
- **Inventory Optimization**: Multi-echelon inventory optimization, ABC analysis.
- **Procurement Optimization**: Supplier evaluation, automated RFQ.
- **Logistics Management**: Route optimization, real-time tracking.
- **Risk Management**: Supply chain risk assessment, BCP.

## Technology Stack
- **Backend**: Python (FastAPI), Java (Spring Boot)
- **Data Processing**: Apache Kafka, Apache Spark
- **ML Infrastructure**: TensorFlow, scikit-learn, MLflow
- **Database**: TimescaleDB, PostgreSQL, Neo4j
- **Real-time Analysis**: Apache Flink, Elasticsearch, Kibana

## Architecture
The system follows a microservices architecture. See [Architecture Documentation](docs/architecture.md) for details.
