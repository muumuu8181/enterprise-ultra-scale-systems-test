# 銀行勘定系システム（プロトタイプ）

このリポジトリには、大規模な銀行業務を処理するために設計された勘定系システムのプロトタイプ実装が含まれています。

## 実装済みの機能（プロトタイプ）

### 勘定系コア
- **顧客管理**: CIF（顧客情報ファイル）の基本構造
- **口座管理**: 普通預金、定期預金などの口座開設・管理
- **取引処理**:
  - 入金 (Deposit)
  - 出金 (Withdrawal)
  - 振込 (Transfer) - 原子性（ACID特性）をシミュレートしたトランザクション管理
- **残高照会**: リアルタイム残高確認

## 計画中の機能（未実装）

以下の機能は将来的な拡張として計画されています。

### 預金系システム
- 利息計算（日割り・月割り）
- 総合口座自動融資

### 為替系システム
- 外国送金（SWIFT連携）
- 代金取立

### 融資系システム
- 証書貸付、手形貸付、当座貸越
- 返済スケジュール管理

### 決済系システム
- 即時グロス決済（RTGS）、ACH連携
- クレジットカード決済

### 情報系システム
- KYC（本人確認）、AML（マネーロンダリング対策）
- リスク管理（信用、市場、流動性）
- 会計（総勘定元帳、財務諸表作成）

## アーキテクチャ

このプロトタイプは、Pythonで実装された勘定系のコアとなる預金および取引処理ロジックに焦点を当てています。
インメモリデータストアを使用し、分散トランザクションの概念実証を行っています。

## ディレクトリ構造

- `src/`: 銀行システムのロジックのソースコード。
- `tests/`: システムのユニットテスト。

## 使用方法

### テストの実行

```bash
python3 -m unittest tests/test_banking.py
```
