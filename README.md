# 宇宙開発向け衛星運用・軌道制御システム

## 概要
本プロジェクトは、宇宙開発における衛星の運用および軌道制御を行うための統合システムです。
軌道決定、姿勢制御、テレメトリ・コマンド処理、ミッション運用などの機能を提供します。

## モジュール構成

### 1. 軌道決定 (Orbit Determination)
- **軌道推定**: レンジング、ドップラー、TLEを用いた推定
- **軌道予測**: 大気抵抗や太陽輻射圧などの摂動を考慮
- **軌道制御**: 軌道修正マヌーバ、デブリ回避

### 2. 姿勢制御 (Attitude Control)
- **姿勢決定**: 太陽センサー、地球センサー、ジャイロなどのデータ処理
- **姿勢制御**: リアクションホイール、スラスタを用いた制御
- **太陽電池パドル指向**: 太陽追尾機能

### 3. テレメトリ・コマンド (Telemetry & Command)
- **ダウンリンク**: ハウスキーピングデータ(HK)、ミッションデータの受信
- **アップリンク**: コマンド送信、パラメータ更新
- **異常監視**: 温度・電圧の異常検知、セーフモード移行ロジック

### 4. ミッション運用 (Mission Operations)
- **観測計画**: 地球観測および撮像スケジュールの立案
- **データ処理**: 画像補正、幾何補正、放射量補正
- **データ配信**: ユーザーへのデータ配信およびアーカイブ

## 技術要件
- **リアルタイム性**: 軌道制御および緊急コマンドへの対応
- **高信頼性**: 冗長系および自律制御の実装
- **宇宙環境対策**: 放射線耐性およびシングルイベント対策を考慮した設計

## ディレクトリ構成
- `src/orbit`: 軌道関連モジュール
- `src/attitude`: 姿勢制御関連モジュール
- `src/telemetry`: テレメトリ・コマンド関連モジュール
- `src/mission`: ミッション運用関連モジュール
- `tests`: テストコード
