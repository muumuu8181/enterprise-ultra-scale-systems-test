# Step 9: セキュリティ・プライバシー仕様 (STEP9_SECURITY.md)

## 1. 概要
重要インフラとしての高いセキュリティ基準と、市民のプライバシー保護を両立させるための包括的なセキュリティ戦略。

## 2. プライバシー保護 (Data Privacy)

### 2.1 データ最小化と匿名化
- **個人情報の扱い**: 市民の移動履歴や個人を特定できるデータは、収集時点で可能な限り匿名化・集計化する。
- **カメラ映像**:
    - **エッジ処理**: 顔認識などの解析は原則エッジノード内で行い、特徴量抽出後に映像データは破棄する（保存しない）。
    - **マスキング**: 必要に応じて映像を送信する場合、顔やナンバープレートにリアルタイムでモザイク処理を施す。
- **位置情報**:
    - 個別の移動軌跡（Trajectory）は保存せず、エリアごとの滞留人口（Population Density）として集計データのみを保存する。

### 2.2 コンプライアンス
- **GDPR準拠**: データの利用目的を明示し、目的外利用をシステム的に制限する。データ保持期間（Retention Policy）を厳格に適用し、期間経過後は自動削除する。

## 3. インフラセキュリティ (Infrastructure Security)

### 3.1 ゼロトラストアーキテクチャ
- 全ての通信（内部マイクロサービス間含む）において、常に認証・認可を行い、暗号化（mTLS）を強制する。信頼できるネットワーク境界を設けない。

### 3.2 産業用制御システム (SCADA/ICS) セキュリティ
- **規格準拠**: IEC 62443 シリーズに基づいたセキュリティ対策を実装。
- **ネットワーク分離**: 制御系ネットワーク（OT）と情報系ネットワーク（IT）の間にエアギャップまたは一方通行ゲートウェイ（Data Diode）を設置し、外部からの直接攻撃を防ぐ。

### 3.3 脆弱性管理と監視
- **レッドチーム演習**: 定期的に模擬サイバー攻撃を行い、侵入検知システムや対応プロセスの有効性を評価・改善する。
- **サプライチェーンセキュリティ**: 使用するOSSライブラリやコンテナイメージの脆弱性スキャンをCI/CDパイプラインで自動化。
