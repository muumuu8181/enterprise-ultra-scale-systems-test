# Requirements

## 1. 機能要件一覧（表形式）

| ID | 機能名 | 優先度 | 詳細説明 |
|---|---|---|---|
| FR-001 | 顧客登録・KYC検証 | 高 | 顧客情報の登録、本人確認書類（KYC）のアップロードと検証プロセス。 |
| FR-002 | 口座開設・閉鎖・凍結 | 高 | 普通預金、当座預金などの口座開設、解約、不正利用時の凍結処理。 |
| FR-003 | 入金処理 | 高 | ATM、窓口、他行からの振込、オンラインでの入金処理。 |
| FR-004 | 出金処理 | 高 | 限度額チェック、残高確認を行った上での出金処理。 |
| FR-005 | 内部振込 | 高 | 同一行内での口座間資金移動。デッドロック防止機構を含む。 |
| FR-006 | 外部振込 | 高 | 全銀システムやSWIFTネットワークを通じた他行への振込処理。 |
| FR-007 | 為替取引・レート管理 | 中 | 多通貨間の為替取引、リアルタイムレートの管理と適用。 |
| FR-008 | 融資申込・審査・実行 | 中 | 融資の申し込み受付、信用スコアに基づく審査、融資実行。 |
| FR-009 | 返済スケジュール生成 | 中 | 元利均等、元金均等方式による返済スケジュールの生成。 |
| FR-010 | 利息計算バッチ | 高 | 預金利息の計算と付与。源泉徴収税（20.315%）の徴収を含む。 |
| FR-011 | 監査ログ記録・改ざん検知 | 高 | 全ての操作ログの記録とハッシュチェーンによる改ざん検知。 |
| FR-012 | AML検知 | 高 | 1000万円以上の現金取引や制裁リストとの照合によるマネーロンダリング検知。 |
| FR-013 | MFA認証・JWT発行・失効管理 | 高 | 多要素認証（MFA）、JSON Web Tokenの発行と無効化管理。 |
| FR-014 | RBAC権限管理 | 高 | 役割ベースのアクセス制御（TELLER, MANAGER, AUDITOR, ADMIN）。 |

## 2. 非機能要件

- **性能**: 10,000 TPS、p95 < 1秒、p99 < 2秒
- **可用性**: 99.999%（年間ダウンタイム5分以下）
- **データ保全**: RPO < 1分、RTO < 10分
- **監査ログ保管**: 7年間
- **暗号化**: AES-256-GCM（保存時）、TLS 1.3（通信時）
- **金額精度**: DECIMAL(19,4)（浮動小数点禁止）

## 3. 用語集（完全版）

| 用語 | 定義 |
|---|---|
| CIF (Customer Information File) | 顧客情報の基本ファイル。顧客を一意に識別するための番号や属性情報を管理する。 |
| KYC (Know Your Customer) | 顧客確認。口座開設時などに顧客の身元確認を行う手続き。 |
| AML (Anti-Money Laundering) | マネーロンダリング（資金洗浄）対策。犯罪収益の移転防止に関する法律や規制への対応。 |
| RTGS (Real-Time Gross Settlement) | 即時グロス決済。取引ごとに即時に決済を行う方式。 |
| ACID | データベーストランザクションの特性。Atomicity（原子性）、Consistency（一貫性）、Isolation（独立性）、Durability（永続性）。 |
| 2PC (Two-Phase Commit) | 分散トランザクションにおいて、全ノードがコミット可能か確認してからコミットするプロトコル。 |
| Saga | 長期間にわたるトランザクションを複数のローカルトランザクションに分割し、失敗時に補償トランザクションを実行するパターン。 |
| HSM (Hardware Security Module) | 暗号鍵の生成、保管、処理を行うための物理的なセキュリティデバイス。 |
| SWIFT | 国際銀行間通信協会。国際的な金融通信ネットワークを提供する協同組合。 |
| 全銀 (Zengin System) | 全国銀行データ通信システム。日本の金融機関間の内国為替取引を中継するオンラインシステム。 |
| Basel III | バーゼル銀行監督委員会が定めた、銀行の自己資本比率や流動性に関する国際的な規制枠組み。 |
| FATCA (Foreign Account Tax Compliance Act) | 米国の外国口座税務コンプライアンス法。米国納税義務者の海外口座情報を収集するための制度。 |
| VaR (Value at Risk) | リスク・バリュー。特定の期間、信頼区間における最大損失予想額。 |
| LCR (Liquidity Coverage Ratio) | 流動性カバレッジ比率。短期的な資金流出に対応できるだけの質の高い流動資産の保有を義務付ける規制。 |
| TELLER | 銀行の窓口係。入出金や振込などの基本的な取引を担当する役割。 |
| Tier 1 Capital | 銀行の中核的自己資本。普通株式や内部留保など、質の高い資本。 |
| Nostro Account | 自行が他行に開設している決済用口座。「我々の口座」の意。 |
| Vostro Account | 他行が自行に開設している決済用口座。「貴行の口座」の意。 |
| Correspondent Bank | コルレス銀行。海外送金などで中継を行う提携銀行。 |
| IBAN (International Bank Account Number) | 国際銀行口座番号。欧州を中心に採用されている国際的な口座番号の統一規格。 |
| BIC (Bank Identifier Code) | SWIFTコードとも呼ばれる、金融機関を一意に識別するためのコード。 |
| Payment Gateway | オンライン決済において、加盟店と金融機関の間で決済情報の処理を行うサービス。 |
| Clearing House | 手形交換所。金融機関間の決済（手形や小切手など）の交換・差額決済を行う機関。 |
| Settlement | 決済。資金や証券の受け渡しを行い、債権債務関係を解消すること。 |
| Reconciliation | 照合。帳簿上の残高と実際の残高、あるいは異なるシステム間のデータを突き合わせて一致確認を行う作業。 |
